# Vestibular Migraine Rehabilitation Exercise Library

Open `index.html` in a modern browser. The page includes nine educational exercise modules, animated schematic demonstrations, symptom-safety notes, and a simple session log.

## Animation preview controls
Use the preview speed and movement/visual-sweep sliders to slow down or widen the on-screen demonstrations, and use Pause/Resume to inspect a movement. These controls affect the illustrations only; they do not prescribe a patient's exercise speed, range, or dose.

## Clinical-use note
This is an educational clinician-review draft, not a validated treatment protocol. Visual patterns are illustrative and are not calibrated in degrees of visual angle or validated optokinetic stimuli. A vestibular rehabilitation clinician should individualize exercises and review the content before clinical use. Do not use the website as a substitute for assessment or individualized advice.
