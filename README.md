# Vestibular Rehabilitation Exercise Library

Mobile-friendly educational website with a browser-based interactive 3D teaching model and visual-stimulus demonstrations.

## Included modules
- Original vestibular migraine learning modules
- Persistent Postural-Perceptual Dizziness (PPPD): graded visual-motion and balance practice
- Vestibulopathy/peripheral vestibular hypofunction: clinician-selected gaze stability and balance work
- BPPV: clinician-directed, diagnosis-specific repositioning information (no generic self-manoeuvre sequence)
- Ménière’s disease: balance rehabilitation between acute episodes, when appropriate
- Orthostatic dizziness: staged position changes and fall-prevention advice

## Open the site
Extract the ZIP and open `index.html` in a modern browser. The 3D viewer uses Three.js from a public CDN, so an internet connection is required for the 3D section.

## Mobile layout
The layout adapts to narrow screens, stacks exercise cards and controls, enlarges touch targets, and uses a full-width mobile 3D viewer. For the most reliable behaviour, use a current version of Chrome, Safari, Firefox or Edge.

## Clinical safety
This is an educational clinician-review draft, not a diagnostic tool, validated treatment device, or individualized prescription. The procedural 3D model is illustrative, not motion-capture or a validated biomechanical simulation. Visual speeds are displayed in pixels per second and are not calibrated degrees-per-second stimuli.

BPPV manoeuvres depend on the affected canal and side; the website intentionally directs users to a trained clinician rather than teaching a generic self-manoeuvre. Orthostatic dizziness can have serious medical causes; fainting, chest pain, shortness of breath, or neurological symptoms require urgent assessment. Ménière’s disease and PPPD also require individualized medical/rehabilitation care.

Before clinical or public use, have all modules reviewed by a vestibular physiotherapist/audiologist and relevant medical clinicians. See `REFERENCES.md`.
