# Vestibular Migraine Rehabilitation Exercise Library

Open `index.html` in a modern browser. The page contains nine educational exercise modules, animated schematic demonstrations, a browser-based visual stimulus lab, safety notes, and a simple session log.

## Visual stimulus lab
- Smooth horizontal moving target with adjustable pixel speed, travel width, and target size.
- Low-contrast moving dot pattern with adjustable pixel speed, contrast, and spacing.
- Start, pause/resume, and reset controls.
- Pixel speeds are screen-relative only; they are not degrees per second and do not constitute a clinical prescription.

## Clinical-use note
This is an educational clinician-review draft, not a validated treatment protocol. Human movement diagrams are instructional schematics, not motion-capture video. Visual stimuli are not calibrated to visual angle and are not validated optokinetic stimuli. A vestibular rehabilitation clinician should individualize exercises and review the content before clinical use. Do not use this website as a substitute for assessment or individualized advice.

See `REFERENCES.md` for source material and literature.


## Interactive 3D teaching model
The page includes a browser-based articulated human model for Exercise 4 (head turns), Exercise 6 (weight shifting), Exercise 7 (sit-to-stand), and Exercise 8 (walking). Users can select an exercise, adjust illustrative preview speed and movement range, pause, reset the camera, and drag to rotate the view.

The 3D scene imports Three.js from a public CDN, so an internet connection is required for that section to load. This procedural model is for educational illustration only; it is not motion-capture, not biomechanically validated, and not a clinical treatment device. Slider settings do not prescribe exercise dose.
